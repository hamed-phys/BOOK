أداة الصيانة البسيطة

تحمّل الأداة النسخ المنشورة أو تستورد نسختين محليتين، ثم تعدّل البيانات داخل ذاكرة المتصفح فقط. لا تحفظ إلى GitHub ولا ترفع PDF ولا تغيّر صلاحيات Google Drive.

لا تستورد ملفًا واحدًا فقط. هذا يمنع بدء تعديل على بيانات ناقصة قد تمحو التاريخ.

1. إضافة كتاب أو تعديل كتاب

بيانات الكتاب

2. إضافة تحديث جديد

بيانات التحديث

3. تحقق ثم نزّل الملفين

المسار الآمن: حمّل أحدث نسختين ← عدّل ← تحقق ← نزّل الملفين ← ارفعهما معًا إلى مجلد data ← راجع الفرق ← Commit.

لم تُحمّل البيانات بعد.

4. JSON قابل للنسخ

إذا فشل زر النسخ بسبب صلاحيات المتصفح، ستحدد الأداة النص تلقائيًا لتنسخه يدويًا.

ما الذي لا تفعله الأداة؟

لا تحفظ شيئًا إلى GitHub، ولا ترفع PDF، ولا تغيّر مشاركة Drive، ولا تحتاج كلمة مرور أو رمز API. التغييرات غير المنزلة تضيع عند تحديث الصفحة.
